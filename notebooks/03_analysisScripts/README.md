# Analysis folder
This folder contain scripts for performing all analyses, including: 

* Celligner integration: script 3.0
* Tuning dropout parameter for protint: script 3.1
* Tuning adversarial training and comparison with cycle consistency: script 3.2
* Run protint with final parameters, classify tumors by cell lines: script 3.3
* Run MOBER, ComBat, Harmony, limma; comparison of the methods: script 3.4
* Cell line projection analysis, including differential analysis and GSEA: script 3.5

## environment
* Script 03.0: run with the celligner environment (celligner_environment.yml, see the envs folder in the repo)
* Script 03.1-5: run with the protint environment (environment.yml)
